This repository hosts the data and code for generating figures for "Uncovering global patterns in the allocation of gross primary productivity to net rhizodeposition".

R version 4.5.2 (https://cran.r-project.org/bin/windows/base/) was used to process the data and generate the figures.

The data and code used to generate the figures presented in the study are available in this repository.

This code was developed for research purposes and may require additional setup to run in other computing environments. Please contact the authors if you need technical assistance with running the code.
